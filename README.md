# Questy 🔬

> **Autonomous R&D, Deep Investigation & Intelligence Framework for Google Antigravity**

Questy is a collaborative research and development intelligence suite built natively for Google Antigravity. It equips your team with seven specialized, institutional-grade skills accessible directly through Antigravity's slash command interface (`/`).

---

## ⚡ The 7 R&D Slash Commands

Whenever this repository is opened in Google Antigravity, typing **`/`** in the chat prompt provides instant access to the full R&D workflow suite:

| Command | Skill ID | Core Capability |
| :--- | :--- | :--- |
| **`/rnd-research`** | `rnd-research` | **Evidence-Led Deep Research**: Systematic hypothesis testing, real-time web investigation, and impartial factual analysis. |
| **`/rnd-struct`** | `rnd-struct` | **Multi-Dimensional Structuring**: Transforms raw facts into rigorous schemas, architectural matrices, and taxonomies. |
| **`/rnd-source`** | `rnd-source` | **Source Verification & Credibility Audit**: Evaluates primary sources, flags bias, detects provenance, and ranks evidentiary confidence. |
| **`/rnd-report`** | `rnd-report` | **Executive Decision-Ready Reports**: Generates concise, high-signal briefings, executive summaries, and action roadmaps. |
| **`/rnd-network`** | `rnd-network` | **Entity & Dependency Mapping**: Models complex relationships, market ecosystems, supply chains, and technical dependencies. |
| **`/rnd-framework`** | `rnd-framework` | **Methodology & Rubric Design**: Creates reusable evaluation criteria, benchmarking scorecards, and testing protocols. |
| **`/rnd-guidelines`** | `rnd-guidelines` | **Analytical Rigor & Truth Standards**: Enforces objectivity, zero-bias validation, and epistemic honesty across tasks. |

## 🚀 Quickstart for Colleagues

When sharing this project with team members:

### 1. Clone the Repository
```bash
git clone https://github.com/parthongit89/Questy_.git
cd Questy_
```

### 2. Open in Google Antigravity
Open the `Questy_` directory in **Google Antigravity** (IDE or CLI).

### 3. Start Using Slash Commands
In the Antigravity chat input box:
1. Type `/`
2. Select any of the `/rnd-*` commands (or type directly, e.g. `/rnd-research What are the top 3 bottlenecks in high-temperature superconducting qubits?`)
3. The Antigravity agent will autonomously load the corresponding skill instructions and execute the research runbook.
