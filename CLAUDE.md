# Claude Code & Anthropic Guidelines: Questy R&D Suite

Welcome to **Questy**. This repository implements a cross-platform, open-source R&D and strategic intelligence suite.

## Slash Commands & Modular Protocols

When the user asks for research or invokes one of the `/ques-*` commands, adapt the corresponding protocol:

- `/ques-research` [topic]: Frame the research question, plan verification steps, gather primary evidence, and deliver an impartial analysis.
- `/ques-struct` [content]: Structure complex findings, taxonomies, schemas, trade-off matrices, or decision trees.
- `/ques-source` [claims/sources]: Assess evidentiary strength, verify provenance, check bias, and flag conflicts of interest.
- `/ques-report` [data]: Produce an executive, decision-ready analytical report tailored to stakeholders.
- `/ques-network` [domain]: Map stakeholders, dependencies, ecosystems, and relational graphs.
- `/ques-framework` [problem]: Design reusable evaluation methodologies, scoring rubrics, or testing procedures.
- `/ques-guidelines`: Enforce core integrity, objectivity, privacy, and research reproducibility standards.

## Code & Operational Standards
- Keep documentation and skill definitions synchronised with `.agents/skills/`.
- Preserve source attribution and maintain neutral, objective language.
